2. 聚簇索引 vs 非聚簇索引

特性 聚簇索引 非聚簇索引
数据存储 叶子节点存储完整数据行 叶子节点存储主键值

二、MySQL锁机制（项目实战）

1. InnoDB锁类型

锁类型 说明 适用场景
记录锁（Record Lock） 锁定单行索引记录 精准控制并发
间隙锁（Gap Lock） 锁定索引间隙，不锁记录本身 防止幻读
临键锁（Next-Key Lock） 记录锁 + 间隙锁 RR级别默认算法
意向锁 表级锁，表示打算加行锁 多粒度锁兼容性检查
插入意向锁 INSERT操作的间隙锁 并发插入优化

临键锁退化规则：

条件 退化结果 说明
等值查询，记录存在 退化为记录锁 只锁住匹配的记录
等值查询，记录不存在 退化为间隙锁 锁住目标位置所在的间隙
范围查询 不退化 锁住范围内所有间隙和记录

2. 事务隔离级别

隔离级别 脏读 不可重复读 幻读 实现方式
READ UNCOMMITTED 可能 可能 可能 无隔离
READ COMMITTED 不可能 可能 可能 MVCC（每次SELECT新ReadView）
REPEATABLE READ 不可能 不可能 可能 MVCC + 间隙锁（首次SELECT的ReadView）
SERIALIZABLE 不可能 不可能 不可能 所有SELECT加共享锁

死锁排查步骤：

死锁预防策略：

策略 说明
按固定顺序获取锁 所有事务先锁Vehicle再锁Task
缩小事务范围 事务中只做数据库操作，不放RPC调用

4. 乐观锁实现

乐观锁 vs 悲观锁：

维度 乐观锁 悲观锁
原理 CAS + version SELECT … FOR UPDATE
冲突处理 失败重试 等待锁释放
适用场景 读多写少 写多冲突多
性能 高（无锁等待） 低（有锁等待）

非分片键查询优化方案：

方案 说明 优缺点
并行查询所有分片 线程池并发查询 简单但浪费资源
索引表 建立order_no→分片位置的映射表 多一次查询但精确

3. 分库分表后的问题与解决

问题 说明 解决方案
跨库JOIN 订单表和用户表不在同一个库 代码层组装/冗余字段/宽表
跨库分页 每个库取前N条，合并排序不准确 禁止深分页/游标分页/ES索引
分布式事务 跨库事务无法保证一致性 Seata AT/TCC模式/本地消息表
主键ID冲突 自增ID在不同库中可能重复 雪花算法生成分布式ID
数据扩容 分片数不够需要扩容 一致性哈希/双写迁移
非分片键查询 只按vehicle_id分片，按timestamp查需全表扫描 索引表/ES辅助查询
跨库排序 多个分片的数据合并后排序 应用层排序/ES
数据迁移 扩容时需要迁移历史数据 双写+增量同步+一致性校验

4. 分布式ID方案

方案 原理 优点 缺点
雪花算法 时间戳+机器ID+序列号 趋势递增、无依赖 时钟回拨问题
UUID 随机生成128位 简单、无依赖 无序、索引效率低
数据库自增 利用数据库auto_increment 简单 单点瓶颈
Redis INCR Redis原子递增 高性能 依赖Redis
号段模式 预分配ID段 减少DB访问 不连续

五、缓存与数据库一致性

1. 四种更新策略

策略 并发问题 一致性 推荐度
先更新DB，再更新缓存 并发写导致数据覆盖 差 不推荐
先更新缓存，再更新DB DB失败导致不一致 差 不推荐
先删缓存，再更新DB 并发读导致脏数据回填 中 可用
先更新DB，再删缓存 极端并发下可能不一致 较好 ★ 推荐

2. 项目实战方案

六、真实项目中的MySQL问题

问题 原因 解决方案
慢查询突增 新上线SQL缺少索引 EXPLAIN分析+添加索引
索引失效 隐式类型转换/函数/左模糊 避免运算、统一类型
死锁频发 事务获取锁顺序不一致 按固定顺序操作、缩短事务
行锁升级为表锁 UPDATE/DELETE未走索引 确保WHERE条件有索引
主从延迟 从库SQL线程单线程重放慢 并行复制、分库降低单库压力
深分页慢查询 LIMIT 1000000,10扫描太多行 延迟关联/游标分页
Using filesort ORDER BY字段无索引 WHERE+ORDER BY建联合索引
Using temporary GROUP BY和ORDER BY字段不同 统一字段或冗余列
大事务阻塞 事务中包含RPC调用 事务中只做DB操作
分库分表后JOIN 跨库无法JOIN 代码层组装/冗余字段/宽表
自增ID不连续 事务回滚或MySQL重启 正常现象，不影响使用
唯一索引死锁 两个事务交替插入相同唯一键 业务层保证唯一、先查再插
连接数耗尽 未关闭连接/慢查询占用 排查慢查询、配置wait_timeout
批量插入太慢 逐条INSERT + autocommit 批量INSERT + rewriteBatchedStatements
分页数据不一致 并发写入导致两次查询间数据变化 使用游标分页或快照读
