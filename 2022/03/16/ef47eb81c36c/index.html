Stream流操作——集合处理的利器

发布于 2022-03-16 分类：技术, 2022, Java基础 👁

前言

在实际场景中，对集合的各种操作——过滤在岗矿工、按部门分组统计、设备状态聚合、预警趋势分析——最初全用for循环一步步处理，代码又长又容易出bug。直到学会Stream，才发现集合操作可以这么优雅。但Stream也不是万能的，踩过不少坑后才算真正掌握。

一、Stream是什么

Stream是Java 8引入的声明式集合处理方式，关注”做什么”而非”怎么做”。

八、何时用Stream，何时用for循环

场景 推荐 原因
过滤/映射/分组 Stream 声明式，简洁
统计/聚合 Stream 内置收集器
集合转Map Stream toMap简洁
简单遍历 for-each 直观
需要修改集合 for循环 Stream不可变
需要索引 for循环 Stream无索引
需要异常处理 for循环 Lambda异常繁琐
复杂多步骤 for循环 更易调试

总结

Stream是2022年实际项目中代码效率提升最大的工具。从冗长的for循环到声明式的链式操作，代码量减少50%以上。核心认知是：Stream追求的是可读性，不是性能。简单场景用Stream更优雅，复杂场景用for循环更可控。不要为了用Stream而用Stream，代码的终极目标是让人读懂。

优化点 做法 效果
避免N+1查询 先批量查再Stream 查询次数从N降到1
原始类型流 mapToInt/mapToLong 避免装箱拆箱
短路操作 findFirst/anyMatch 提前终止

十三、最佳实践总结

场景 推荐 原因
过滤/映射 Stream 声明式简洁
分组/统计 Stream 内置收集器
集合转Map Stream toMap方便
简单遍历 for-each 直观
修改集合 for循环 安全
异常处理 for循环 Lambda繁琐
IO操作 for循环 先批量再处理

中间操作方法

方法 说明 示例
filter 过滤元素 stream.filter(d -> d.getStatus().equals(“online”))
map 转换元素 stream.map(Device::getName)
flatMap 扁平化转换 stream.flatMap(d -> d.getSensors().stream())
distinct 去重 stream.distinct()
sorted 排序 stream.sorted(Comparator.comparing(Device::getName))
limit 取前N个 stream.limit(10)
skip 跳过前N个 stream.skip(5)
peek 查看(调试) stream.peek(d -> log.info(d.getName()))
mapToInt 转IntStream stream.mapToInt(Device::getAlarmCount)
mapToLong 转LongStream stream.mapToLong(Device::getId)
mapToDouble 转DoubleStream stream.mapToDouble(Device::getTemperature)
takeWhile 取满足条件的 stream.takeWhile(d -> d.getTemperature() < 50)
dropWhile 丢弃满足条件的 stream.dropWhile(d -> d.getTemperature() < 50)

终端操作方法

方法 说明 示例
forEach 遍历 stream.forEach(d -> process(d))
forEachOrdered 有序遍历 stream.forEachOrdered(d -> process(d))
toArray 转数组 stream.toArray(Device[]::new)
reduce 归约 stream.reduce((a, b) -> a + b)
collect 收集 stream.collect(Collectors.toList())
min 最小值 stream.min(Comparator.comparing(Device::getTemperature))
max 最大值 stream.max(Comparator.comparing(Device::getTemperature))
count 计数 stream.count()
anyMatch 任意匹配 stream.anyMatch(d -> d.getTemperature() > 50)
allMatch 全部匹配 stream.allMatch(d -> d.getStatus().equals(“online”))
noneMatch 无匹配 stream.noneMatch(d -> d.getAlarmCount() > 100)
findFirst 找第一个 stream.findFirst()
findAny 找任意一个 stream.findAny()

收集器 说明 示例
toList 收集到List Collectors.toList()
