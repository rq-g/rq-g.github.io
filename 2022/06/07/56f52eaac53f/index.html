MyBatis-Plus逻辑删除与乐观锁——数据安全双保险

发布于 2022-06-07 分类：技术, 2022, MyBatis 👁

前言

实际场景中，设备数据是核心资产。一次误操作删除了一张设备表的数据，差点导致矿井监控中断。从那以后，我开始认真研究逻辑删除和乐观锁，确保数据安全。逻辑删除防止数据被误删，乐观锁防止并发修改冲突。两者结合，是实际项目数据安全的双保险。

逻辑删除

什么是逻辑删除？

逻辑删除不是真正删除数据，而是将”删除标志”字段修改为已删除状态，查询时自动过滤已删除数据。

什么是乐观锁？

乐观锁工作流程

  • 线程A 线程B
  • 读取 device (version=1) 读取 device (version=1)
  • | |
  • 修改 stock=9 |
  • | 修改 stock=8
  • UPDATE … SET version=2 |
  • WHERE version=1 |
  • 成功！version变为2 |
  • |
  • UPDATE … SET version=2
  • WHERE version=1
  • 失败！version已变为2
