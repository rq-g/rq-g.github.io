审批流实战——状态机与流程控制

发布于 2022-12-23 分类：技术, 2022, 综合实战 👁

前言

在实际场景中，审批流程是最核心的业务之一。矿山作业涉及大量安全审批：下井作业审批、爆破作业审批、设备检修审批、物料领用审批——每种流程的审批节点和流转规则都不同。最初用if-else硬编码处理状态流转，随着业务复杂度上升，代码越来越难以维护。后来用状态机模式重构，状态流转规则变得清晰可维护，审批日志让每一步操作都有迹可循。

本文以实际项目中的”下井作业审批”为例，从数据库设计到状态机实现，完整展示审批流开发的全过程。

下井作业审批流程

下井作业审批流程：

  • 矿工提交 → 班组长审批 →
  • 通过 → 安全主管审批 →
  • 通过 → 矿长审批 → 通过/驳回
  • 驳回 → 班组长重新审批
  • 驳回 → 矿工修改/取消
